# Сообщение для публикации

Сегодня у части пользователей Astral были проблемы с подключением: сайт и приложение могли показывать ошибки соединения, а часть запросов отвечала `502`.

Что произошло:

- после частичного падения Docker-стека не все инфраструктурные сервисы поднялись в правильном порядке;
- `redis`, `postgres`, `minio`, `cassandra`, `gateway`, `livekit` и reverse-proxy потребовали ручного восстановления;
- API поднялся некорректно после сбоя зависимостей и временно не обслуживал часть запросов, из-за чего клиенты видели проблемы с подключением.

Что мы сделали:

- восстановили весь стек и переподняли зависимые сервисы;
- проверили публичные точки входа, API и realtime gateway;
- добавили автоматический watchdog, который отслеживает `502`, состояние контейнеров и сам запускает recovery-подъём.

Извиняемся за сбой. Сейчас сервис восстановлен и работает штатно. Мы отдельно усилили автоматическое восстановление, чтобы такие падения не оставались без реакции.
