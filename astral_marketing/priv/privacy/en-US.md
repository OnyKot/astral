## 2. Information We Process

### 2.1. Information you provide

- **Account:** email, username, password (Argon2id hash), date of birth; phone number if you enable 2FA.
- **Profile:** avatar, bio, status, display name, and other optional details.
- **Content:** messages, files, images, voice/video, reactions, community information.
- **Payments:** for Plutonium purchases, card details are handled by **Platega** and **other payment providers chosen by Astral**. We receive only limited billing metadata (status, timestamps, country/partial card data if provided).
- **Support:** contents of tickets and attachments.

### 2.2. Information collected automatically

- Technical data: IP address, browser, OS, device, language.
- Usage: features used, sessions, aggregated counters (without reading message text), crash and performance metrics.
- Security logs: logins, setting changes, rate limits, API errors, abuse signals.
- Coarse IP geolocation (country/region/city) for security and eligibility.

### 2.3. Information from others

- From other users (mentions, interactions).
- From service providers (email/SMS delivery, payment confirmations, infrastructure alerts).
- From open sources and abuse/IP reputation services.

### 2.4. Special categories

We do not ask for special-category data (health, religion, biometrics, etc.). If you post such data yourself, you do so at your own risk.
