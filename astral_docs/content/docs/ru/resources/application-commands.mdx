---

Команды приложений — основной способ взаимодействия пользователей с ботом через интерфейс Astral. Они появляются в подсказке при вводе `/` в текстовом канале.

## Типы команд

| Тип | Значение | Описание |
| --- | --- | --- |
| CHAT_INPUT | 1 | Слеш-команда, появляется при вводе `/` |
| USER | 2 | Появляется в контекстном меню пользователя |
| MESSAGE | 3 | Появляется в контекстном меню сообщения |

## Объект команды

| Поле | Тип | Описание |
| --- | --- | --- |
| id | snowflake | Уникальный ID команды |
| application_id | snowflake | ID родительского приложения |
| guild_id | ?snowflake | ID сервера (для серверных команд) или `null` для глобальных |
| name | string | Имя команды, 1–32 символа |
| description | string | Описание, 1–100 символов |
| type | integer | Тип команды (см. выше) |
| options | ?array | Параметры команды (макс. 25) |
| default_member_permissions | ?string | Требуемые права для использования |
| dm_permission | ?boolean | Доступна ли в ЛС (по умолчанию `true`) |
| version | integer | Автоинкрементная версия |

## Параметры команд (Options)

| Поле | Тип | Описание |
| --- | --- | --- |
| type | integer | Тип параметра |
| name | string | Имя, 1–32 символа |
| description | string | Описание, 1–100 символов |
| required | ?boolean | Обязательный ли параметр |
| choices | ?array | Предопределённые варианты (макс. 25) |
| options | ?array | Вложенные параметры для подкоманд |

### Типы параметров

| Тип | Значение | Описание |
| --- | --- | --- |
| SUB_COMMAND | 1 | Подкоманда |
| SUB_COMMAND_GROUP | 2 | Группа подкоманд |
| STRING | 3 | Текст |
| INTEGER | 4 | Целое число |
| BOOLEAN | 5 | Да / Нет |
| USER | 6 | Упоминание пользователя |
| CHANNEL | 7 | Упоминание канала |
| ROLE | 8 | Упоминание роли |
| MENTIONABLE | 9 | Пользователь или роль |
| NUMBER | 10 | Дробное число |

## Эндпоинты

### Глобальные команды

Глобальные команды доступны на всех серверах, где есть ваш бот. Обновление может занять до 1 часа.

| Метод | Маршрут | Описание |
| --- | --- | --- |
| GET | `/applications/{app.id}/commands` | Список глобальных команд |
| POST | `/applications/{app.id}/commands` | Создать глобальную команду |
| GET | `/applications/{app.id}/commands/{cmd.id}` | Получить команду |
| PATCH | `/applications/{app.id}/commands/{cmd.id}` | Обновить команду |
| DELETE | `/applications/{app.id}/commands/{cmd.id}` | Удалить команду |
| PUT | `/applications/{app.id}/commands` | Перезаписать все глобальные команды |

### Серверные команды

Серверные команды доступны мгновенно, только на указанном сервере.

| Метод | Маршрут | Описание |
| --- | --- | --- |
| GET | `/applications/{app.id}/guilds/{guild.id}/commands` | Список серверных команд |
| POST | `/applications/{app.id}/guilds/{guild.id}/commands` | Создать серверную команду |
| GET | `/applications/{app.id}/guilds/{guild.id}/commands/{cmd.id}` | Получить команду |
| PATCH | `/applications/{app.id}/guilds/{guild.id}/commands/{cmd.id}` | Обновить команду |
| DELETE | `/applications/{app.id}/guilds/{guild.id}/commands/{cmd.id}` | Удалить команду |
| PUT | `/applications/{app.id}/guilds/{guild.id}/commands` | Перезаписать все серверные команды |

**Пример создания:**

```json
{
  "name": "ping",
  "description": "Проверить, жив ли бот",
  "type": 1,
  "options": []
}
```

## Лимиты

| Действие | Лимит |
| --- | --- |
| Список команд | 5 за 5 секунд |
| Создание | 5 за 10 секунд |
| Обновление | 5 за 10 секунд |
| Удаление | 5 за 10 секунд |
| Полная перезапись | 2 за 30 секунд |

## Рекомендации

1. **Используйте серверные команды при разработке** — они обновляются мгновенно.
2. **Регистрируйте команды один раз при старте бота**, а не при каждом перезапуске.
3. **Имена команд — строчными буквами**, допустимы дефисы.
4. **Используйте `default_member_permissions`** для ограничения доступа к опасным командам.
