Ниже перечислены основные dispatch-события, которые обычно нужны боту.

## Анатомия dispatch-пакета

```json
{
  "op": 0,
  "t": "MESSAGE_CREATE",
  "s": 42,
  "d": {}
}
```

## Практический паттерн

Обычно бот работает так:

1. получает событие из Gateway
2. анализирует `d`
3. принимает решение
4. выполняет REST-запрос в API

Пример:

- пришёл `MESSAGE_CREATE`
- текст равен `!ping`
- бот делает `POST /channels/:channel_id/messages`
